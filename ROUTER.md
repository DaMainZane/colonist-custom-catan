# Router

Find the files for a task here, then open only those. Do not read whole folders. Search for a symbol before opening a file. File descriptions: `INDEX.md`. Registration methods, hooks and registries: `EXTENSION POINTS.md`. Step-by-step for a new piece, action, addon, tech node or client overlay: `RECIPES.md`; a working example addon to copy: `src/packs/_template/demo.ts`.

Content is data: an addon registers it through `PackApi` (see `EXTENSION POINTS.md`). The engine in `src/shared` should not need edits. The hand-written glue still outside the registry is marked **glue**; R6 to R8 of `Modular Rework Plan.md` remove it.

## Glue names

The generated `INDEX.md` rows no longer list these. Taken from the old hand-written rows, not re-checked against the code: search for the name before trusting it.

- `server/socket.ts`: `upgradeBridge` runs `upgrade_bridge`, `spendFish` runs `spend_fish`, `feedSea` runs `feed_sea`, `drivePirate` runs `drive_off_pirate`, `discardCards` passes `wild` for fish, `clickVertex` with `piece: 'net'` builds a net.
- Fields sent to the client (since R7a the Tidebound ones come from `VIEW_DATA` entries in the addon files; `pieceCosts` and `wildTokens` are still built in `server/view.ts`): per-player `pieceCosts`, `bridgeUpgradeCost`, `wildTokens` (same visibility as the hand), `netSpots`, `netsLeft`, `feedSpots`, `feedCost`, public `fishIcons`, and `hexOverlays` plus `tide` when Tides is on. Related: `wrecks`, `pirates`, `pirateDrives`.
- `client/render/board.ts`: layers `boardFishLayer`, `boardWrecksLayer`, `boardPiratesLayer`; `clickFeedSpot` (feed mode, `setBuildMode('feed')`); `clickEdge` opens the bridge picker; the overlay layer is rewritten only when its markup changes.
- `client/icons.ts`: `fishGroundMarkup` (fish with boost pips), `wreckMarkup`, the fish token, piece shapes. `client/render/overlay.ts`: `renderElevationMarkup`, flood colors from `--flood-*` tokens.
- `client/render/hand.ts`: `onClickHandWild` (pick a fish for a discard or open the spend sheet). `client/render/drawer.ts`: discard of cards and fish, spend-a-fish sheet.
- `server/main.ts`: `/api/memory/export` and `/api/memory/import`. `server/runtime.ts`: `mapRegistryFor` (room map registry, cached per addon set). `server/rooms.ts`: `rebindPlayerId` (reconnect).
- Names of registries and modifiers (`COST_MODS`, `RATIO_MODS`, `PORT_IDLE_CHECKS`, `HARBOR_RATIO_MODS`, `STEAL_COUNT_MODS`, `DISCARD_LIMIT_MODS`, `SEVEN_STEPS`, ...) are in `EXTENSION POINTS.md`.

## Always

- After adding or changing imports: `npm run headers:write`. After adding, moving or re-describing a file: `npm run index`. Then `npm run typecheck` and `npm test`.
- Layer rules (enforced by `tests/architecture.test.ts`): `shared` imports only `shared`; a pack imports `shared`, itself and `packs/base`; `server` never imports `client`; `client` imports only `client` and `shared`. No new circular imports.
- Behavior-preserving work leaves `tests/golden.snapshot.json` untouched.
